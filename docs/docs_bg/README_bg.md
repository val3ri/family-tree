# 🌳 Семейно дърво (Family Tree Visualization)

![Семейно дърво интерфейс](docs/images/family_tree_interface.png)

> 🤖 **AI проект** — Изграден изцяло с помощта на [Claude Code](https://claude.ai/code) & [Google Antigravity](https://antigravity.google).

Интерактивно уеб приложение за визуализиране, създаване и управление на семейно родословно дърво. Проектът използва контейнеризирана архитектура, модерен Angular фронтенд с графична визуализация чрез D3.js и бърз FastAPI бекенд с PostgreSQL база данни.

---

## ✨ Основни функционалности (v1.0)

* 📊 **Интерактивна D3.js графа**: Визуализация на роднинските връзки в дървовидна структура с плавно привличане и подравняване по поколения.
* 👥 **Детайлни профили и Биография**: Поддръжка на разширени лични данни:
  * Имена, снимки и бележки.
  * Дати, време и места за раждане и смърт.
  * Образование, професии и места на пребиваване.
* 💍 **Поддръжка на бракове и разводи**:
  * Въвеждане на дати и места на сключване на брак.
  * Отразяване на разводи (визуализирани автоматично с пунктирани червени линии на графа за лесно разграничаване).
* 🔍 **Интуитивна навигация**:
  * Свободно придвижване (Pan) и мащабиране (Zoom) с мишка/тъчпад.
  * Бутони на екрана за бърз Zoom (`+` / `-`).
  * Бутон за **автоматично центриране** (⌖), който изчислява координатите на всички хора и напасва графа перфектно според размера на вашия екран.
* 📱 **Мобилен дизайн (Responsive UI)**:
  * Адаптивни контроли, оптимизирани за екрани от всякакъв размер.
  * На мобилни телефони детайлите за избран човек се отварят в плавен, плъзгащ се отдолу панел (**Bottom Sheet**) с размазан фонов слой (backdrop blur).
* 💾 **Система за резервни копия (JSON Backup)**:
  * Сваляне (Експорт) на всички данни с едно кликване в единичен JSON файл.
  * Възстановяване (Импорт) на архива директно през уеб интерфейса с транзакционна сигурност (базата се опреснява само ако файлът е напълно валиден, без риск от счупване).

## ⚡ Бърз старт (Quick Start)

За да стартирате проекта локално на вашия компютър, е нужно да имате инсталирани **Docker** и **Docker Compose**.

1. Клонирайте хранилището:
   ```bash
   git clone https://github.com/your-username/family-tree.git
   cd family-tree
   ```

2. Стартирайте контейнерите на заден план:
   ```bash
   docker compose up --build -d
   ```

3. Отворете вашия браузър на адрес:
   - **Приложение**: [http://localhost](http://localhost) (порт 80)
   - **Бекенд документация (Swagger)**: [http://localhost:8000/docs](http://localhost:8000/docs)

---

## 📂 Примерни данни за бърз тест
В корена на проекта ще намерите файла **`sample-family-tree.json`**, който съдържа готово семейно дърво с 3 поколения, бракове, разводи и биографични бележки (съответстващо на снимката по-горе).

1. Отворете сайта `http://localhost`.
2. Натиснете бутона **„Импорт“** в горния десен ъгъл.
3. Изберете файла `sample-family-tree.json` и потвърдете.
4. Дървото ще се визуализира веднага!
